# README Design Contract

## readmeArchetype
Journey card.
## readmeNarrativeVoice
Clear transit accessibility coordinator.
## readmeSectionPattern
Traveler card, thread rules, station checklist, service notice.
## readmeMotif
Punched route ticket.
## requiredFactsPlacement
Identity and state are on the traveler card, mechanics and consensus are thread rules, setup and tests are the station checklist, and limitations are the service notice.
## bannedReadmePatterns
No botanical notebook, incident dispatch, badge row, or generic feature list.
## proofOfDifference
This follows a linear traveler route rather than an emergency map or botanical specimen and uses a short public-service voice.
