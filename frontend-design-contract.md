# Frontend Design Contract

Timeline-replay-interface. A horizontal tactile route thread is the first surface. The visual metaphor is a transit accessibility journey card. Custom components are JourneyThread, ConstraintPocket, BarrierCounter, and PassageTicket. Animations are Weave Advance, Ticket Punch, Barrier Knock, Station Arrival, and Consensus Thread. Palette is cream, transit blue, coral, mint, and ink. No map, tree, dashboard cards, hero, feed, or purple gradient.
